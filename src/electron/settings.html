TMAG / CONTROL

控制中心

連線、驗證與服務開關都在這裡同步。

Web UI 位址 http://127.0.0.1:7080/
01

Meshtastic 連線

選擇 TCP 或 Serial，變更會即時套用。

若列表為空，請確認裝置已連線後再按重新整理。
TCP 模式輸入 IP（例如 192.168.1.50）；Serial 模式請從上方清單選擇裝置，系統會自動套用。
02

CallMesh Key

輸入後立即驗證，成功才會解鎖服務。

Key 會保存在本機設定檔
03

APRS 設定

調整上報伺服器與信標頻率。

預設為 asia.aprs2.net，可依需求調整
預設每 10 分鐘發送一次，可調整為 1-1440 分鐘
04

Traceroute

自動探索路徑與頻率設定。

直收時不會送出 traceroute，可自行關閉或調整間隔。
05

Web UI

GUI 不顯示 Web UI，請用瀏覽器開啟。

關閉後只保留後端服務。
06

TenManMap 分享

資料會同步給合作地圖。

不建議停用，僅在特殊需求時取消。
07

重置資料

清除本地資料與 API Key。

尚未更新

變更會自動儲存並重新套用設定。
