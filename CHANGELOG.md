## 2.0.0-rc.1

The first CMClient 2.0 release candidate introduces the Agent/Gateway/Web/
Desktop/CLI composition, durable Jobs and updates, protocol-aware Proxy,
deterministic Position/APRS processing, native Desktop packages, and
source-bound Docker OCI artifacts. Service deployments use bounded, retained,
redacted Agent/Gateway/SCM JSONL rather than discarded child output. See the
complete [RC release notes](docs/releases/2.0.0-rc.1.md)
for artifact names, verification gates, limits, and the remaining human
production-approval boundary.

This entry does not declare a stable `2.0.0` release.
